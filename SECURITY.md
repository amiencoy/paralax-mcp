# Security policy

Do not open a public issue containing credentials, private context, signing keys, capsules, database contents, generated gateway configuration, or raw model conversations.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/amiencoy/paralax-mcp/security/advisories/new). Include a minimal synthetic reproducer and affected version. Revoke affected bonds and end connected model sessions if approved context may have been exposed.

This project is an experimental reference implementation. The supported security boundary and deliberate limits are documented in `docs/ARCHITECTURE.md`.
